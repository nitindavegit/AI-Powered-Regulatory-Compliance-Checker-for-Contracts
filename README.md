# AI-Powered Regulatory Compliance Checker for Contracts

An intelligent, AI-driven solution for automating contract review and compliance verification across multiple regulatory frameworks and jurisdictions.

## Project Statement

This project develops an advanced AI system that automates the review and updating of contracts to ensure compliance with regulatory standards across various jurisdictions, including GDPR, HIPAA, and industry-specific regulations. The solution leverages Large Language Models (LLMs) such as OpenAI GPT and Meta LLaMA, combined with LangChain, to:

- Automatically detect missing or incomplete clauses
- Assess compliance risks with detailed explanations
- Recommend amendments based on latest regulatory updates
- Integrate data from multiple sources (Google Sheets, websites, emails)
- Provide real-time compliance checks and notifications

By automating contract management, this system significantly reduces manual review efforts and minimizes compliance risks.

## Key Features

✅ **Automated Compliance Checking** - Supports multiple regulatory frameworks and jurisdictions
✅ **Real-time Risk Assessment** - Context-aware clause recommendations and risk scoring
✅ **Continuous Monitoring** - Automatic application of regulatory updates to active contracts
✅ **Multi-source Integration** - Aggregates data from Google Sheets, websites, and emails
✅ **Intelligent Clause Detection** - Identifies missing, incomplete, or non-compliant clauses
✅ **Streamlined Management** - Reduces manual intervention and improves efficiency

## Tech Stack

- **LLMs**: OpenAI GPT, Meta LLaMA
- **Framework**: LangChain
- **Data Integration**: Google Sheets API, Web Scraping
- **Backend**: Python
- **Monitoring**: Real-time notification system

## Outcomes

- Automated compliance checking for contracts across multiple regulatory frameworks
- Real-time risk assessment and context-based clause recommendations
- Continuous monitoring and application of regulatory updates to active contracts
- Streamlined contract management process with reduced manual intervention
